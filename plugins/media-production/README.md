# Media Production

Plugins that produce or edit media: video, audio, narration, images.

| Plugin | Hosted | What it does |
|---|---|---|
| [`argo-guide`](https://github.com/khorum-oss/argo) | external (`khorum-oss/argo`) | Turns Playwright demo scripts into product demo videos with AI voiceover, overlays and transitions. |

```bash
/plugin install argo-guide@khorum-ai-marketplace
```
