# Observability

Plugins that let you watch, trace or visualize what Claude Code and its subagents do.

| Plugin | Hosted | What it does |
|---|---|---|
| [`foreman-vision`](https://github.com/khorum-oss/foreman-vision-pub) | external (`khorum-oss/foreman-vision-pub`) | Live pixel-art office in the browser: each session a floor, each subagent a worker at a desk. Uses hooks on every event. |

```bash
/plugin install foreman-vision@khorum-ai-marketplace
```
